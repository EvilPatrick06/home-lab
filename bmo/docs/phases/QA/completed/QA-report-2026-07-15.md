### LED mode buttons desync from reality: disabled LEDs still show "static" highlighted, and clicking the highlighted mode can never turn them on

- **Category:** bug
- **Severity:** medium
- **Domain:** bmo
- **Discovered by:** QA Agent
- **During:** settings tab → RGB Lights

**Description:** Server LED state is `{mode:"static", enabled:false}` (LEDs physically off; startup log: `[led] Restored state: ready, brightness=100%, disabled=True`). The UI highlights whatever `ledState.mode` says — so "static" renders as the active mode while the lights are actually off. Worse, `setLedMode()` (`bmo.js:3646`) toggles: clicking the already-highlighted mode sends `{mode:"off"}`. And `POST /api/led/mode {"mode":"off"}` responds `ok:true` with `mode:"static"` (set_mode("off") flips `enabled` but `get_full_state()` keeps reporting the retained mode), while the client optimistically sets its local mode to "off" — client and server now disagree. Net effect: a user looking at "static" highlighted cannot turn the LEDs on by clicking it (the click sends "off"), and the UI's active-mode highlight is not trustworthy.

**Reproduction:**
1. With LED state `enabled:false, mode:"static"` — observe "static" highlighted in RGB Lights.
2. Click "static" → request body is `{"mode":"off"}`; response reports `mode:"static", enabled:false`.
3. UI now highlights "off"; server still says "static".

**Expected behavior:** The active highlight reflects `enabled` (highlight "off" when disabled); the API's returned `mode` folds `enabled=false` into `"off"`; clicking a mode while disabled enables that mode.

**Hypothesis / root cause:** `app.py:1699` `api_led_mode` + LED controller keep `mode` and `enabled` as separate fields but the frontend contract only knows `mode`; `bmo.js` toggle logic assumes mode==="off" is the only off signal.

**Suggested action:** Normalize: report `mode:"off"` whenever `enabled` is false, and make set_mode(m) with m≠off also set enabled=true.

**Environment:** Pi loopback · normal · connected · LED hardware present but disabled

**Related files:** `bmo/pi/app.py:1674-1723`, `bmo/pi/web/static/js/bmo.js:3646`, LED controller in `bmo/pi/hardware/`
