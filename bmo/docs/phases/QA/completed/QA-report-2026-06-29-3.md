### Empty `<img src="">` placeholders trigger spurious requests to the page URL

- **Category:** bug
- **Severity:** low
- **Domain:** bmo
- **Discovered by:** QA Agent
- **During:** TV/Home — broken-image scan across the SPA

**Description:** Three `<img>` elements carry an empty `src=""` while inactive/hidden: the now-playing thumbnail (`w-16 h-16 rounded-lg object-cover`), the camera-stream image (`w-full h-full object-contain`), and the snapshot-preview image (`alt="Snapshot preview"`). A browser treats `src=""` as "resolve against the current document URL", so each issues a wasteful request to `/bmo` itself and reports `naturalWidth === 0` (i.e. they register as broken images even though they're not visible). All three are off-screen at the time, so there's no visible glitch — but the spurious self-requests and broken-image state are real.

**Reproduction:**
1. Load `/bmo`.
2. In the console: `[...document.querySelectorAll('img')].filter(i=>!i.getAttribute('src')||i.naturalWidth===0)` → returns the three elements above, each with `src=""`.

**Expected behavior:** Inactive images should omit `src` entirely (or bind to a 1×1/transparent placeholder) so the browser issues no request and doesn't flag them broken.

**Hypothesis / root cause:** Alpine bindings of the form `:src="cond ? realUrl : ''"` (e.g. the camera overlay `:src="showCameraOverlay ? '/api/camera/stream' : ''"` in `index.html`, and the now-playing/snapshot thumbnails) emit `src=""` when the condition is false. Prefer `x-bind:src` that removes the attribute when falsy, e.g. `:src="cond ? realUrl : null"`, or guard with `x-show`/`<template x-if>`.

**Suggested action:** Replace the empty-string fallbacks with `null` (attribute removed) or render the `<img>` only when it has a real source.

**Environment:** LAN/localhost loopback · kiosk off · connected · viewport 1024

**Related files:** `bmo/pi/web/templates/index.html` (camera overlay `:src`, now-playing thumbnail, snapshot preview)

**Console output (if any):** none (the requests are silent)

**Screenshot(s):** n/a (elements hidden)
